Página 3: Interactividad con JavaScript

JavaScript agrega comportamiento a la página: responde a eventos, modifica el contenido y se comunica con servidores.

Variables

Las variables guardan datos que el programa puede consultar y modificar durante su ejecución.

Eventos

Los eventos, como un clic o el envío de un formulario, disparan funciones que responden al usuario.

Peticiones

Con AJAX o fetch se pueden consultar y enviar datos a un servidor sin recargar la página.

Es la representación en memoria de la página que JavaScript puede leer y modificar.
