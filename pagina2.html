Página 2: Estilos con CSS

CSS controla la apariencia de la página: colores, tamaños, márgenes y distribución de los elementos.

Selectores

Los selectores indican a qué elementos se aplicará un estilo, por clase, por id o por etiqueta.

Modelo de caja

Cada elemento está formado por contenido, relleno, borde y margen que determinan su tamaño.

Diseño flexible

Flexbox y Grid permiten acomodar los elementos de forma responsiva en distintos tamaños de pantalla.

Es el sistema que decide qué regla CSS tiene prioridad cuando varias coinciden con un mismo elemento.

Bootstrap es un framework que ofrece estilos y componentes listos para usar y responsivos.
